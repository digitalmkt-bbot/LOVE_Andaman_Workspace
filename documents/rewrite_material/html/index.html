03 Conventions

Backend: framework-neutral

PostgreSQL DDL, REST endpoint tables, JSON shapes and language-agnostic pseudocode. No Fastify, FastAPI, ORM or validation-library code anywhere.

Frontend: React SPA

Doc 03 is the one place a frontend framework is named — tokens as CSS custom properties, components as React prop contracts.

Currency and time

Thai Baht, Asia/Bangkok (+07:00). Bilingual Thai/English UI throughout, with the Thai-script type rules stated in 03.

Bugs are marked

Where current behaviour is a defect rather than a rule, the spec says so and specifies the correct behaviour instead. Do not port the bug.

Supersedes decision D3 allotment_v2/docs/rewrite/README.md records decision D3 — “Vite React SPA + Fastify API” — as binding. These specs are framework-neutral on the backend by explicit instruction, so D3’s backend half no longer holds. Update that file so the plan of record does not contradict its own specs. The React SPA half of D3 stands.
