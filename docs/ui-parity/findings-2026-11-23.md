# UI parity · hand-checked findings · 2026-11-23

**What was compared.** Legacy (`origin/lk-inbox` 8f76f252, `server.js`, `DATA_BACKEND=relational`) and the new
frontend (`main` 7c17a9a4 + operation-backend `main` d212ccd), with the same data on both sides: the parity pipeline's
local copies of legacy and of the cutover import (`legacy_ui`, `operations_ui` on localhost:55433). Both apps used an
admin login, Bangkok time, a 1440×900 screen, and today, 2026-11-23.

**What ran.** `test/uiparity/run.mjs` opened 76 pages and 449 page × toggle states. That was one full run with 2 app
pairs, plus reruns with 1 pair for the 23 pages whose data loads slowly. Of the states, 55 were the same, 97 had the
same layout with different numbers, and 297 differed. The machine-made table of every state is
[report-2026-11-23.md](report-2026-11-23.md), and every page and toggle is listed in [inventory.md](inventory.md).

**How the cause was decided.** Each row below was checked by hand, not only by the script's guess:
- **sync lag:** legacy's text is not in `main`'s code at all. `main` was last synced on 2026-11-08 and is 135
  lk-inbox commits behind.
- **backend:** the server refuses, is slow, or does not hold or compute what legacy shows.
- **frontend:** the server has the data (checked with a direct API call or SQL), but the screen does not show it,
  or shows it differently.

Numbers that differ on a matching layout (Dashboard, Daily, Fleet, Costing and others) are **not** listed one by
one. They follow from the data parity gaps (`pipeline:parity`: 8 of 33 checks differ) and from legacy's copy being
slightly newer than the import (contracts 1140 vs 1124, seat locks 3008 vs 2998).

## How far to trust this

- One run on 2026-11-23 against copies taken by the last parity pull. Legacy's copy is a little newer than the
  import, so small count differences are expected.
- A "toggle" is found by its label and handler. Toggles whose labels differ only by a number share one key, and only
  the first is clicked. Write-like buttons (save, delete, assign, …) were never clicked.
- Dialogs: only buttons named `open…`/`show…`/`…Detail`/`…Modal` were opened. Forms and editors were not.
